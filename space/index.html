whittle-mcp

Trim what your agent reads, and measure what it kept.

Paste, trim, check. Paste a test log, stack trace, JSON, git diff or OpenAPI document. See what is kept, the tokens saved, and expand anything that was omitted. The trimming runs in your browser with Python (Pyodide); what you paste stays in this tab. Token counts here are an estimate (characters / 4); the CLI uses tiktoken. Short outputs save little (they have little to cut); the bigger and noisier the output, the more it saves.
