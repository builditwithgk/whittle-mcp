    "body": "### PR summary\r\n\r\nCloses #33384.\r\n\r\n**What does the patch change?** When two views may overlap, the patch copies the source before writing, except for simple 1-D shifts that already have a safe copy order. It also handles both `.flat` assignment forms. The copy keeps the source dtype so the final assignment can apply the mask and cast.\r\n\r\n**Why keep the old path for plain shifts?** Take `x[1:] = x[:-1]`. If NumPy starts at the right and works backwards, it reads every value before overwriting it. That already gives me the right answer, so there’s no reason to allocate another array for it.\r\n\r\n**What does it cost, and for whom?** The extra copy costs time and memory when the views overlap and the patch takes a temporary. In the 64 MiB test on Linux, `x[::2] = x[:n]` went from about 8 ms to 19.5 ms. The 8 ms run gave the wrong answer. Separate arrays don’t need that copy. We don’t have a good timing yet for tiny assignments. When the memory ranges overlap and the views don’t qualify as a plain shift, the patch takes a copy even if the old code happened to give the right answer.\r\n\r\n**What was tested, and what wasn’t?** I reproduced the bug on Linux. The patch adds six regression tests covering unequal strides, masked copies, both `.flat` write paths, repeated source values, an array subclass, partial-byte overlap and broadcasting. In the nine-element check, 200 of 13,332 assignments gave the wrong result before the patch. All 13,332 gave the expected result afterward.\r\n\r\nI also ran the full suite on Linux x86-64. With the patch, 52,557 tests passed, 4 failed and 10 errored. I got the same 4 failures and 10 errors on unchanged NumPy on the same machine. Those tests either need Meson, which wasn’t installed, or check installation paths. None exercises array assignment. The patch has been tested on Linux x86-64, and the cost on tiny assignments still needs measuring.\r\n\r\n### First time contributor introduction\r\n\r\nI’m Rohit, and I work on OpenSceneSense, a Python library for video analysis.
